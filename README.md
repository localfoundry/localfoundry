**Robin Bially** — I build developer tools and native macOS apps, mostly around LLM infrastructure.

- **[search-rotation](https://github.com/localfoundry/search-rotation-mcp)** — one MCP server for web search and page extraction: rotates across the free tiers of seven providers, fails over automatically when a quota runs out, and ships a local dashboard for keys, engine order and quota status.
- **[opencodex](https://github.com/localfoundry/opencodex)** — universal provider proxy for OpenAI Codex and Claude Code.
- **[buffr](https://github.com/localfoundry/buffr)** — VCR-style record and replay for API traffic.
- **[DotShelf](https://github.com/localfoundry/DotShelf)** — native macOS editor for dotfiles and config files.
- **[SMARTastic](https://github.com/localfoundry/SMARTastic)** — native macOS drive health monitor with daily write-volume tracking.

Homebrew packages live in the [tap](https://github.com/localfoundry/homebrew-tap): `brew install localfoundry/tap/search-rotation`, `brew install --cask localfoundry/tap/dotshelf`, `brew install --cask localfoundry/tap/smartastic`.

Based in Magdeburg, Germany.
